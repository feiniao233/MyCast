# Synthetic search diagnostics previews

`search-diagnostics-100/150.png` are generated by
`TestActualMatchingFieldDiagnosticsDPI` in MyGo's headless renderer at 100%/150%.
All application names, AppID/paths, alias and source status are dedicated
synthetic fixtures. The timestamp belongs to the synthetic test batch, not a
personal acceptance history. No real inventory or screenshot is captured.

The scrollable source panel reports the actual winning user-alias pinyin field,
original file adapter and a partial scan batch with unknown unobserved entries.
Closing it restores the unchanged search input. This does not demonstrate
native Windows materials, keyboard/IME or desktop pointer acceptance.
