# Synthetic startup snapshot previews

`snapshot-settings-100/150.png` and `snapshot-pending-100/150.png` are rendered
by MyGo's headless `TestSnapshotControlsAndPendingPreviewDPI` using dedicated
synthetic names, paths and icons at 100%/150% scale. They are not desktop captures
and contain no user inventory, clipboard or private paths.

The settings image shows a checked draft; Cancel still leaves the live
default-off preference unchanged. Pending rows cannot launch, open a location,
or change preferences. The complete-source live scan must replace each row.
