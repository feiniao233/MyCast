# MyCast 0.1.0-alpha

首个 Windows 原生 Go 启动器 alpha。当前这份说明供发布负责人审查；正式
主分支合并、标签、prerelease 和仓库公开由负责人协调。

## 本版内容

- 原生 MyGo 搜索面板、热键、托盘、单实例和设置；深色/浅色/系统主题。
- 开始菜单及桌面应用索引、中文名、英文别名、离线拼音、收藏和最近启动。
  已知普通文档/目录目标从应用结果中排除，长查询限制过度分散匹配。
  已证实丢失的普通本地 exe 目标也被排除；权限拒绝、离线/未知及特殊入口保留。
  重扫提供及时反馈并保留当前查询、选择和可视位置，启动失败会排队刷新。
- 手动开启后的未来纯文本历史，仅存内存；完整预览、暂停、删除、清空和到期。
  热键捕获的目标可尝试定向回填；安全检查不满足时提供“仅复制”。
- 本地四则运算及用户创建的 HTTP(S) 快捷链接。
- 材质/圆角/主题下拉框/状态详情修正，原创深靛蓝与青蓝几何 M 图标，
  同时接入 EXE 多尺寸资源、窗口大小图标与托盘。

## 下载与运行

预期支持 Windows 10/11 x64。下载单个 Windows ZIP，解压到普通用户可写目录，
运行 `MyCast.exe`，默认热键为 Ctrl+Alt+Space。程序未签名；系统可能显示
未知发布者提示。没有安装器，不自动安装开机启动或修改系统安全设置。

相邻 `.sha256.txt` 校验外层 ZIP，包内 `SHA256SUMS.txt` 校验每个交付文件。
`BUILDINFO.txt` 和 `MANIFEST.json` 标明精确提交、Go 1.27.2、MyGo v0.4.6
与构建目标。包内对应源码 ZIP 包含该提交及 vendored 依赖，可按
[构建说明](../README.md#构建) 使用 `go build -mod=vendor` 离线构建。
项目及原创图标采用 AGPL-3.0-or-later，依赖许可证和声明均随包附带。

## 已知限制与验收范围

真实 Windows 交互尚有未验证项目：IME 候选确认/取消、成功自动回填、
托盘/热键、高 DPI 和多屏。本 alpha 接受这些已知限制；自动化检查不能
理解为全部实机项目通过。

- 图标 PE 内容和隐藏窗口大小图标接口可自动检查；真实任务栏/Explorer/
  托盘外观及图标缓存、高 DPI 切换仍未在本执行环境目视验证。
- 请求 Windows Acrylic 与原生圆角，支持情况按系统而异，有纯色后备。
  离屏预览和 DWM 属性成功不证明实际合成效果。
- 微软拼音等真实候选输入仍需后续复测；当前有组合输入保护及合成回归。
- 自动回填依赖目标支持 `WM_PASTE`。管理员窗口、浏览器、自绘控件等可能
  拒绝或忽略；调用成功不证明文字已插入。无法确认时使用“仅复制”后手动粘贴。
- 不含 UWP 专用枚举、文件全文搜索、自动更新、开机启动或持久剪贴板历史。
  未知/特殊快捷方式与可执行包装程序保留，可能仍出现非 GUI 入口。
- Windows 托盘在 Explorer 重启后的恢复尚未保证。

默认不记录或导入当前剪贴板；开启后仅处理未来文本，历史退出清空，不上传。
停止使用时通过托盘退出，再删除解压目录；若需清除普通偏好，可另外删除
`%APPDATA%\MyCast\settings.json`。没有剪贴板历史文件或开机启动项需要卸载。

详细证据和限制见 [ACCEPTANCE.md](ACCEPTANCE.md)、[ICONS.md](ICONS.md)
与 [PACKAGING.md](PACKAGING.md)。
